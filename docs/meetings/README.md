# Meeting Notes

This directory contains all meeting agendas, notes, decisions, and action items related to the project.

## Purpose

The goal of these meeting notes is to:
- Track project progress
- Document team decisions
- Record assigned tasks and responsibilities
- Maintain accountability across the team

## Meeting Format

Each meeting document should generally include:

- Date and time
- Attendees
- Agenda
- Discussion notes
- Decisions made
- Action items
- Next meeting time

## Naming Convention

Meeting files should follow this format:

```text
meeting-01.md
meeting-02.md
meeting-03.md
