# Android Project Structure

This repository includes a minimal native Android foundation for spotra using Kotlin and Jetpack Compose.

```text
app/
└── src/main/
    ├── AndroidManifest.xml
    ├── java/com/appetizers/spotra/
    │   ├── MainActivity.kt
    │   └── presentation/
    │       ├── home/
    │       └── theme/
    └── res/
        ├── drawable/
        ├── mipmap-anydpi-v26/
        └── values/
```
